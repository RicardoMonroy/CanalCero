# CanalCero

App Android para comunicarse por LoRa con nodos [Meshtastic](https://meshtastic.org), pensada para cuando hay cero señal: apagones y rodadas en moto por zonas sin cobertura.

Estado: esqueleto inicial. Visión y hoja de ruta en [docs/VISION.md](docs/VISION.md).

## Compilar

```bash
./gradlew assembleDebug
```

Requiere JDK 17 y Android SDK (API 37).
